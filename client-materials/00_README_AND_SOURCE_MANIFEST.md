# Vision Plus — Client Materials Manifest

## Purpose

This folder contains the source materials that should be supplied to Claude Code as the primary client-reference package for the Vision Plus website project.

## Files

### 01_Vision_Plus_Approved_Content.txt
Approved client website/company content. Treat this as the source of truth for the supplied business copy and terminology.

### 02_Vision_Plus_Strategy_and_Brand.pdf
Client strategy/brand document containing market research, positioning, brand foundation, market opportunity, sitemap, and color-palette options.

### 03_Vision_Plus_Website_Sitemap.png
Visual reference of the client-provided website sitemap.

### 04_Vision_Plus_Color_Palette.jpg
Visual brand/color-palette reference. IMPORTANT: Option B is approved. Option A is rejected.

### 05_Vision_Plus_Reference_Image.jpg
Additional client-provided visual reference supplied with the project materials. Inspect it and determine its relevance from the image itself; do not assume its purpose from the filename.

## Confirmed project decisions

- Brand direction: Option B only.
- Option A: rejected; do not use it.
- Languages: English (default), Arabic (RTL), Simplified Chinese/Mandarin Chinese.
- No CMS.
- No admin dashboard.
- No login/authentication.
- Company Profile: client will provide a Canva embedded presentation; the website should provide a polished responsive page for the embed rather than recreating the presentation.
- Partners: homepage logo carousel; partners page can show logo + partner name. Do not invent partner data.
- Contact form: one email recipient + Google Sheets.
- Qatar and Egypt locations exist; final addresses, phones, emails, and map details are pending client delivery and must remain placeholders.
- Website imagery: do not invent/generate final imagery. Build intentional image slots/placeholders and document exact required dimensions for the designer.
- Approved content includes the supplied Solutions, Services, Industries, and company/about content.
- Products must not be invented if the source materials do not provide product data.

## Important instruction

Claude Code should inspect all files in this directory, including visual files, before producing the master project plan.
